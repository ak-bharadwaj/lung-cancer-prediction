# Lung Cancer Datasets & Cohorts

This repository incorporates multiple datasets and multi-tier cohorts to address the challenges of small sample sizes and class imbalance in medical ML classification:

## 1. Primary Benchmark Cohort: `lung_cancer_cohort_1309.csv`
- **Total Records:** 1,309
- **Predictors (15 features):**
  - Demographic: `GENDER` (M/F), `AGE` (continuous 20–95)
  - 13 Survey / Clinical Symptoms: `SMOKING`, `YELLOW_FINGERS`, `ANXIETY`, `PEER_PRESSURE`, `CHRONIC_DISEASE`, `FATIGUE`, `ALLERGY`, `WHEEZING`, `ALCOHOL_CONSUMING`, `COUGHING`, `SHORTNESS_OF_BREATH`, `SWALLOWING_DIFFICULTY`, `CHEST_PAIN` (Scale: 1 = No/Low, 2 = Yes/High)
- **Target:** `LUNG_CANCER` (`YES`: 1,144 [87.39%], `NO`: 165 [12.61%])
- **Purpose:** Primary training and evaluation dataset for the CatGBM ensemble pipeline. Provides sufficient statistical sample volume (n=1,309) for reliable holdout testing (n=197) and tight bootstrap confidence intervals.

## 2. Kaggle 1,000-Patient Dataset: `raw/cancer_patient_data_sets.csv`
- **Source:** Kaggle (`thedevastator/cancer-patients-and-air-pollution-a-new-link` via `kagglehub`)
- **Total Records:** 1,000
- **Features (23 clinical and environmental predictors):**
  - `Age`, `Gender`, `Air Pollution`, `Alcohol use`, `Dust Allergy`, `OccuPational Hazards`, `Genetic Risk`, `chronic Lung Disease`, `Balanced Diet`, `Obesity`, `Smoking`, `Passive Smoker`, `Chest Pain`, `Coughing of Blood`, `Fatigue`, `Weight Loss`, `Shortness of Breath`, `Wheezing`, `Swallowing Difficulty`, `Clubbing of Finger Nails`, `Frequent Cold`, `Dry Cough`, `Snoring`
- **Target:** `Level` (High: 365, Medium: 332, Low: 303) and Binary Elevated Cancer Risk (697 Elevated vs 303 Low).
- **Dedicated Pipeline:** `ml/cancer_patient_pipeline.py` provides end-to-end 5-fold CV benchmarking, holdout test evaluation (99.33% Accuracy, 0.9998 ROC-AUC), and reports at `reports/cancer_patient_model_comparison.json` and `reports/cancer_patient_test_evaluation.json`.
- **Note on Deduplication:** Audit revealed 152 unique feature profiles repeated across the 1,000 records. Validated via `validate_cancer_patient_dataset` and benchmarked across both stratified and profile splits.

## 3. Original Baseline Survey Dataset: `raw/survey_lung_cancer.csv`
- **Source:** Kaggle / UCI Machine Learning Repository
- **Total Records:** 309
- **Target:** `LUNG_CANCER` (`YES`: 270 [87.38%], `NO`: 39 [12.62%])
- **Limitations:** Only 39 negative cases total; standard 15% test split yields only 6 negative cases, causing volatile metrics and wide bootstrap confidence intervals.

## 4. Synthetic Stress-Test Cohort: `synthetic_cohort_1000.csv`
- **Generated by:** `ml/synthetic_generator.py`
- **Total Records:** 1,000
- **Conditioning:** Fitted using a multivariate Gaussian copula preserving empirical covariance, joint symptom correlations, and class conditional probabilities.
